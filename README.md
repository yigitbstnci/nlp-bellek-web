# NLP Araştırma Defteri

Literatür taraması, model karşılaştırması ve bellek sistemleri araştırmasının
herkese açık web yayını.

**Web sitesi:** https://yigitbstnci.github.io/nlp-bellek-web/

Bu depo yalnız yayınlanan sayfalar ve sayfalardan bağlantı verilen araştırma
eklerini içerir. Ana geliştirme deposu ve onun Git geçmişi bu depoya aktarılmaz.

GitHub Pages, `main` dalının kökünden yayın yapar. Güncellemeler, özel çalışma
kopyasından yayın dosyalarının yeniden dışa aktarılması ve bu depoya gönderilmesiyle yapılır.
